# Project Overview

## Neural Navigator — Job Portal

Neural Navigator is a team project built to connect job seekers and recruiters through a modern, full-stack job portal.

## Project Purpose
This project provides a centralized platform for:
- recruiters to post and manage job listings,
- candidates to search jobs, submit applications, and upload resumes,
- administrators to review and track hiring activity.

## Repository Structure
- `backend/` — Java backend source, DAO, service, model, server, and database utilities
- `frontend/` — HTML, CSS, and JavaScript user interface
- `uploads/` — stored resume uploads
- `xampp_database_schema.sql` — SQL schema for MySQL database
- `RUN_BACKEND.bat` — script to start the backend server

## Getting Started
1. Set up the MySQL database using `xampp_database_schema.sql`.
2. Run the backend server with `RUN_BACKEND.bat`.
3. Open the frontend files from the `frontend/` folder in a browser.

## Notes
- This repository uses a simple Java HttpServer backend.
- The frontend is built with HTML, CSS, and vanilla JavaScript.
